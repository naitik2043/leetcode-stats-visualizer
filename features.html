THE LEETMETRIC TOOLKIT

Track the work.
Understand the pattern.

LeetMetric brings public LeetCode statistics, personal practice tracking and transparent learning tools into one workspace. Official profile data, user-entered notes and derived suggestions are kept clearly distinct.

01 / PROFILE

Public profile analytics

Look up solved counts, difficulty distribution, accepted and total submissions, global ranking and available contest statistics without sharing LeetCode credentials.

AVAILABLE
02 / ACTIVITY

Submission heatmap

Review the public activity calendar, active days and current streak when LeetCode returns calendar data.

AVAILABLE · DATA-DEPENDENT
03 / CONTESTS

Contest performance

Explore current and peak rating, global contest rank, participation and rating history when the profile has attended rated contests.

AVAILABLE · DATA-DEPENDENT
04 / COMPARISON

Profile comparison

Compare difficulty, submissions, topic coverage, contest and calendar signals side by side. Share a comparison link or export a CSV.

AVAILABLE
05 / INTELLIGENCE

DSA performance intelligence

See balanced difficulty signals, recent activity windows, lower solved-count topic candidates and evidence-linked practice recommendations.

AVAILABLE
06 / ROADMAP

Personalized DSA roadmap

Generate 7-day, 30-day or 90-day plans from available topic and difficulty signals. Check off weeks locally and export the plan as JSON.

AVAILABLE · BROWSER-SAVED PROGRESS
07 / CODE LAB

Static code review lab

Choose C++, Java, Python, JavaScript or C. Inspect common loop, sorting and collection patterns plus an edge-case checklist. Analysis runs in your browser.

AVAILABLE · HEURISTIC ONLY
08 / READINESS

Interview preparation self-assessment

Combine a disclosed DSA practice index with your own ratings for CS fundamentals, project ownership, communication, mocks and resume alignment.

AVAILABLE · SELF-ASSESSMENT
09 / REPORTS

Progress report exports

Generate report previews and export JSON or CSV. Private history appears only when the signed-in account owns snapshots for the selected username.

AVAILABLE
10 / HISTORY

Historical progress

Save one private profile snapshot per UTC day and review solved-count trends over time. Snapshots are retained for up to 180 days.

AVAILABLE · SIGNED-IN USERS
11 / GOALS

Personal practice goals

Create 7-day or 30-day solved-problem goals with progress measured against a saved snapshot baseline.

AVAILABLE · SIGNED-IN USERS
12 / REVISION

DSA revision and mistake journal

Record problems, topics, revisit reasons, mistake types and notes; track queued, revisiting and mastered items. Private mistake-pattern summaries are derived from these records.

AVAILABLE · SIGNED-IN USERS
13 / CODE VAULT

Private solution workspace

Open the separately deployed Paste Vault using a one-time authenticated handoff. Save code snippets, language variants, notes and revisions there.

AVAILABLE · REQUIRES PASTE VAULT CONFIG
14 / ACCOUNT

Account and privacy controls

Register, sign in, reset a password when email delivery is configured, manage a saved username and request account deletion with owned-data cleanup.

AVAILABLE · REQUIRES DATABASE CONFIG
15 / THEME

Accessible presentation

Use a responsive multi-page interface, saved light/dark theme preference and system-theme fallback.

AVAILABLE
TRANSPARENT BY DESIGN

Measured data is not the same as generated advice.

LeetMetric's practice index is a transparent learning signal, not a hiring score. Topic counts can overlap and are not mastery ratings. The Code Review Lab uses static pattern heuristics; it does not compile or execute code. Roadmap completion is stored in the current browser. AI coaching, automated code execution and multi-platform aggregation are not shipped in this release.
