Questions, answered.

A few practical details about using LeetMetric and what the product currently supports.

What is LeetMetric?

LeetMetric is an independent dashboard for visualizing public LeetCode statistics and understanding problem-solving activity.

Do I need to share my LeetCode password?

No. Public profile lookup only needs a public LeetCode username. Never share your LeetCode password, session cookie, or authentication token with this app.

Why create an account?

An account is intended for saving your preferred username and accessing a personal dashboard. Account creation requires the site's MongoDB environment to be configured.

Are the statistics official?

Statistics are requested from LeetCode's public GraphQL endpoint. Availability and field definitions can change, so LeetMetric cannot guarantee uninterrupted upstream access.

Does LeetMetric already have AI coaching?

AI coaching is on the roadmap. It is not part of the current production release and should not be treated as an available feature yet.

Can I compare profiles?

Profile comparison is planned. The current release focuses on an individual public profile overview.

What happens to my account data?

Account data is intended to be stored in MongoDB. Review the Privacy Policy for the planned data categories, security controls, and retention approach.

What if I cannot sign up or reset my password?

Account actions require MongoDB and JWT secrets. Password-reset emails additionally require a configured email provider. If setup is incomplete, the app returns a clear configuration message rather than pretending the action succeeded.

Is LeetMetric affiliated with LeetCode?

No. LeetMetric is an independent community project and is not affiliated with, endorsed by, or sponsored by LeetCode.
